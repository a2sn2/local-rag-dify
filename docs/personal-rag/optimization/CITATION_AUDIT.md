## 1. آلية الاستشهادات في منصة Dify

توفر بنية Dify نوعين من آليات الاستشهاد والإسناد المرجعي (Attribution Mechanisms):

### 1. الإسناد الهيكلي عبر بيانات الواجهة والـ API (`retriever_resources`)
- عند تنفيذ عقدة `knowledge_retrieval` وتوليد الإجابة، يُلحق خادم Dify كائناً برمجياً `retriever_resources` في استجابة الـ API وواجهة الويب، يتضمن:
  - `dataset_name`: اسم قاعدة البيانات (`ALHassan Personal Knowledge Base`).
  - `document_name`: اسم المستند الأصلي (`ALHassan_Baligh_ALShami_Local_RAG_Knowledge_Base.md`).
  - `segment_id`: المعرف الفريد للمقطع المستخدم في قاعدة Weaviate.
  - `score`: درجة التشابه الدلالي المحسوبة.
  - `content`: نص المقطع المعتمد حرفياً.

### 2. الإسناد السياقي داخل نص الإجابة (In-Text Grounding)
- يتم توجيه النموذج التوليدي `qwen3.5:4b` عبر موجه النظام (System Prompt) للإشارة إلى الأقسام والمسميات المعتمدة داخل الوثيقة، مثل:
  - الاستشهاد بـ: `(بحسب السجل المهني الموثق)` أو `(وفقاً لبيانات مشروع التخرج)`.
  - ذكر حالة التوثيق بدقة (مثال: "مشروع موثق برابط مستودع" مقابل "مشروع ذو إثبات مستقل غير مكتمل").
