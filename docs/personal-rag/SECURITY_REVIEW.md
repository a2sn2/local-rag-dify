## 2. احتواء المنافذ والشبكة المحلية (Network & Port Containment)

تم التحقق من مطابقة جميع الحاويات لقواعد الاحتواء المحلي الصارمة:
- **منافذ الاستماع للمضيف:**
  - البوابة العامة Nginx: `127.0.0.1:80->80/tcp` و `127.0.0.1:443->443/tcp` (مقيدة حصراً بعنوان الاسترجاع المحلي Loopback).
  - خدمة الإضافات Plugin Daemon: `127.0.0.1:5003->5003/tcp` (مقيدة حصراً بـ Loopback).
  - انعدام وجود أي منافذ مفتوحة على `0.0.0.0` أو بطاقات الشبكة الفيزيائية الخارجية (LAN/Wi-Fi).
- **قواعد جدار حماية ويندوز (Windows Firewall Hardening):**
  - قاعدة المنفذ 11434 لـ Ollama: `LocalRAG_Ollama_TCP_Inbound` مفعلة ومقيدة حصراً بنطاق WSL2 الديناميكي (`172.19.160.0/20`).
  - سياسة اجتياز الحافة: `EdgeTraversalPolicy = Block`.
  - القواعد المتساهلة القديمة لـ Ollama (TCP و UDP): معطلة بالكامل (`Enabled=False`).
  - منع الوصول الخارجي: محمي تماماً ومؤكد ضد أي استدعاءات من الشبكة الفيزيائية.

## 3. ضوابط الخصوصية ومنع تسريب البيانات الحساسة (Privacy & Anti-Leakage Controls)

1. **استبعاد تاريخ الميلاد والعمر:**
   - محجوبان تماماً ومؤكدان في الموجه البرمجي كمنطقة امتناع إلزامي.
2. **استبعاد أرقام وهواتف المراجع المهنية الخاصة:**
   - حظر كلي على إيراد أرقام أو أسماء المشرفين الأكاديميين أو مسؤولي الشركات السابقة. الاستجابة النظامية: "المراجع متاحة عند الطلب عبر القنوات الرسمية".
3. **حماية أسرار العمل المصرفي والتقنية المالية (Fintech Security):**
   - حظر قطعي لأي محاولة لاستدراج المساعد لإفشاء أكواد خلفية، أو مفاتيح تشفير، أو قواعد بيانات، أو معاملات عملاء محفظة جيب.
4. **حماية البيانات المالية والشخصية:**
   - حظر التخمين أو الإفصاح عن الرواتب، الدخل، الحصص، أو الميزانيات.
5. **حماية مستودع Git العام:**
   - استبعاد ملفات البيانات الخام، ونسخ قواعد البيانات، ومفاتيح البيئة الحساسة من أي تتبع في Git (`.gitignore`).

## 4. تقييم متانة الموجه ضد هجمات كسر القيود (Prompt Injection & Jailbreak Resilience)

- **الهجمات الإيحائية (Roleplay & Pretend):**
  - عند محاولة المستخدم الطلب من المساعد تجاهل القواعد السابقة وتقمص شخصية لا تلتزم بالسياق، يفرض الموجه العودة إلى السياق المرفق ورفض الخروج عنه.
- **الأسئلة المضللة (Misleading Queries):**
  - أسئلة المشاريع الوهمية (مثل تنظيم رحلات في مطار دبي) تقابل فوراً بمسار الامتناع الصريح لعدم وجود سند في المقاطع المسترجعة.
- **التوجيه الإجباري عبر شجرة الـ DAG:**
  - في حال لم يعثر الاسترجاع على أي نص ذي صلة، فإن العقدة `evidence_check` تقطع الطريق حتمياً قبل وصول الطلب إلى النموذج اللغوي، مما يحقق حماية هيكلية على مستوى تدفق البيانات (Architectural Guardrail).
