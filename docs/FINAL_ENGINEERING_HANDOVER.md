## 10. إرشادات التشغيل والاستئناف والتعافي (Runbook & Recovery)

### أ. التشغيل اليومي الآمن:
```powershell
Set-Location "C:\Users\alhassanalshami\local-rag"
.\scripts\start-local-rag.ps1
```
يقوم السكربت بالتحقق من Ollama وتشغيل حاويات Dify بترتيب الاعتمادية والتأكد من استجابة البوابة على `http://127.0.0.1`.

### ب. الإيقاف الآمن وتحرير الموارد:
```powershell

.\scripts\stop-local-rag.ps1
```
يقوم بإيقاف الحاويات بأمان، وتفريغ نماذج Ollama من كرت الشاشة VRAM، وحماية أحجام التخزين دون حذف أي بيانات.

### ج. أخذ نسخة احتياطية مشفرة جديدة ومحدثة:
```powershell
Set-Location "C:\Users\alhassanalshami\local-rag"
.\scripts\backup-local-rag.ps1
```

### د. النقل أو التعافي على جهاز ثالث مستقبلاً:
1. استنساخ المستودع: `git clone https://github.com/a2sn2/local-rag-dify.git`
2. نسخ ملف النسخة الأحدث `backup_...enc` إلى مجلد `backups` ومفتاح `backup.key` إلى `.secrets`.
3. سحب النموذجين: `ollama pull qwen3.5:4b` و `ollama pull bge-m3:latest` (أو نسخ مجلد `.ollama/models`).
4. تنفيذ أمر الاستعادة الشامل:
   ```powershell
   .\scripts\restore-local-rag.ps1 -BackupFile ".\backups\backup_...enc" -Force
   ```
5. بدء المنظومة: `.\scripts\start-local-rag.ps1`.
